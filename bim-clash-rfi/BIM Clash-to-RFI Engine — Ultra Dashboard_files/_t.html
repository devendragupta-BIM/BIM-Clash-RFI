📋 Step-by-Step Setup in n8n Cloud
Node 1 — Webhook Trigger
Create → Add Node → Webhook
Method: POST · Path: /bim-rfi
Copy the URL — paste it in Upload XML tab
Node 2 — Parse XML (Code node)
Language: JavaScript
Parse {{$json.xml}} with DOMParser
Extract all clash objects into array
Node 3 — Split In Batches
Loop over each clash item
Batch size: 1 (one clash at a time)
Prevents rate limit on Groq
Node 4 — HTTP Request (Groq AI)
URL: https://api.groq.com/openai/v1/chat/completions
Auth: Bearer token (your Groq key)
Body: JSON with clash data as prompt
Node 5 — Gmail Node
Connect your Gmail account
To: {{$json.assigned_email}}
Subject: [{{$json.severity}}] RFI - {{$json.clash_id}}
Attach PDF from previous node
Node 6 — Google Sheets
Append row to your tracker sheet
Map: RFI No., Severity, Assigned, Status
Auto-updates clash status dashboard
🤖 Groq AI — Finetuning Guide
What finetuning does here
Trains the model to write RFIs in YOUR exact format — same headings, same code references, same tone. Without finetuning it writes generic text. With it, every RFI sounds like a senior BIM coordinator from your team.
Step 1 — Collect training data
Gather 20-50 real RFI documents your company has written. These become your training examples.
Step 2 — Format as JSONL
Convert each RFI into:
{"messages":[{"role":"user","content":"clash data..."},{"role":"assistant","content":"RFI text..."}]}
Step 3 — Run on Google Colab (free)
Use Unsloth + Llama 3.1 8B
Runtime: T4 GPU · ~45 minutes
Upload your JSONL · run notebook · done
Step 4 — Deploy via Groq
Upload finetuned model to Groq
Replace model name in n8n HTTP node
Every RFI now matches your exact style

🚀 Quick Start — 5 Steps
1
Add your employees — Go to Employees tab. Add each engineer with their discipline. This controls who gets which RFI.
2
Get Groq API key — Go to console.groq.com → API Keys → Create key → Paste in Upload tab
3
Set up Gmail App Password — Google Account → Security → 2FA → App Passwords → Mail → Generate
4
Set up n8n Cloud workflow — See n8n Workflow tab for exact node-by-node setup
5
Upload clash XML → Run — Go to Upload XML tab, drop your file, click Run Engine
